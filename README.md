## 📖 Описание

Плагин **Status Adder** для клиентов **exteraGram** и **AyuGram**.

Кастомные статусы в стиле Discord в имени аккаунта с быстрым переключением между ними.

---

## 📥 Установка

1. Перейдите во вкладку [**Releases**](https://github.com/MaxExteraPlugins/status_adder/releases/latest).
2. Скачайте файл плагина `status_adder_v1.9.0.plugin`.
3. Отправьте файл в Telegram (в «Избранное») или откройте его через проводник в exteraGram / AyuGram.
4. Нажмите на сообщение с плагином и выберите **«Установить плагин»**.

---

## 📋 Совместимость

* **exteraGram:** `>= 12.1.1`
* **AyuGram:** `>= 12.1.1`
* **Plugin SDK:** `>= 1.4.3.3`
